# Captured device configuration

These small text files were read from the X96 Max Plus Ultra (board `ohm`) Android 11 vendor image. They describe the tested IR protocol and key maps; they are not universal to every X96 remote.

`remotecfg` is a vendor executable and is intentionally not included. Obtain it from the matching device's `/vendor/bin/remotecfg` and place it with these files under the local, ignored `input/vendor/` directory before building.
