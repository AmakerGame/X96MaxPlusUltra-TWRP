# Тимчасовий запуск TWRP із USB (без запису boot_a)

У папці `dist/usb-test/` є два файли: `aml_autoscript` і `twrp.img`. Скрипт читає `twrp.img` з USB і виконує завантаження в пам’ять; він не містить команд запису в `boot_a`. Recovery матиме доступ до розділів, тому під час тесту нічого не змінюйте.

1. Підготуйте USB-флешку FAT32; збережіть її вміст окремо.
2. Скопіюйте **обидва** файли з `dist/usb-test/` у корінь флешки без перейменування.
3. Вимкніть приставку. Вставте флешку, утримуйте фізичну кнопку RESET і подайте живлення. Тримайте RESET приблизно 5–7 секунд, потім зачекайте 1–2 хвилини.
4. Після появи TWRP перевірте лише екран, час, список розділів і керування мишкою/пультом. Не запускайте Install, Wipe, Format Data, Restore і не монтуйте розділи вручну.
5. Для виходу виберіть Reboot → System. Якщо recovery не стартувало, вимкніть приставку, вийміть флешку та завантажте Android звичайно.

USB-запуск — безпечніший спосіб перевірити сам факт старту, але не гарантує сумісність усіх функцій TWRP. Якщо бачите помилку, сфотографуйте екран; не прошивайте інші розділи навмання.
