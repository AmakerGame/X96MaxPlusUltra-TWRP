# Временный запуск TWRP с USB (без записи boot_a)

В `dist/usb-test/` находятся два файла: `aml_autoscript` и `twrp.img`. Скрипт читает `twrp.img` с USB и загружает его в память; команд записи в `boot_a` в нём нет. Recovery получает доступ к разделам, поэтому во время проверки ничего не изменяйте.

1. Подготовьте USB-флешку FAT32; заранее сохраните её содержимое.
2. Скопируйте **оба** файла из `dist/usb-test/` в корень флешки без переименования.
3. Выключите приставку. Вставьте флешку, удерживайте физическую кнопку RESET и подайте питание. Держите RESET примерно 5–7 секунд, затем ждите 1–2 минуты.
4. После появления TWRP проверьте только экран, время, список разделов и управление мышью/пультом. Не запускайте Install, Wipe, Format Data, Restore и не монтируйте разделы вручную.
5. Для выхода выберите Reboot → System. Если recovery не стартовало, выключите приставку, извлеките USB и запустите Android обычным способом.

USB-запуск — более безопасный способ проверить сам факт старта, но не подтверждает совместимость всех функций TWRP. Если появилась ошибка, сфотографируйте экран; не прошивайте другие разделы наугад.
